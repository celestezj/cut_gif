# GIF Splitter（GIF 分段截取工具）

一个用于精确查看 GIF 播放时间、打点并截取任意时间段导出为新 GIF 的桌面小工具。

播放 GIF 时实时显示当前播放到的毫秒数，可随时暂停并记录时间节点，选好两个节点后一键将该时间段内的画面导出为独立的 GIF 文件。适合从长 GIF（如屏幕录像、监控片段）中切出一小段。

## 功能

- **实时时间显示**：画面左上角显示当前播放位置（毫秒）及播放 / 暂停状态。
- **快速暂停 / 继续**：主循环 240Hz 轮询按键事件，空格键在事件到达的当帧立即冻结时间，暂停延迟约 4ms。
- **时间节点打点**：
  - 按 `P` 记录当前时刻，最多记录 **2 个**节点；
  - 节点会直接标注在画面上（信息栏文字 + 底部进度条上的红色刻度）；
  - 已有 2 个节点后再按 `P` 为**无效操作**，不会有任何变化；
  - 按 `Esc` 可清空所有已记录的节点，重新开始。
- **分段导出（像素级无损）**：两个节点齐备后按 `O`，导出两节点之间的画面为新 GIF：
  - 文件名：`<原文件名>_split.gif`，保存在原文件同目录；
  - 直接提取原 GIF 中**量化前的原始索引帧**，并沿用原始**全局调色板**与每帧时长，不做任何重新量化，因此不会出现重新编码常见的抖动噪点和模糊光晕；
  - 子 GIF 的第一帧是完整合成画面（保证打开瞬间即为整幅图像），其像素颜色被精确映射回原始全局调色板（零误差），其余帧沿用原始增量帧；
  - 输出结构（单一共享调色板 + 增量帧）与原文件一致，在 Pillow、ffmpeg 及各类浏览器 / 看图器中表现一致。
- **点击进度条跳转**：鼠标点击底部进度条任意位置，立即跳转到对应时刻并自动进入暂停状态，按空格即可从该位置继续播放。
- **正确渲染局部帧 GIF**：按 GIF 规范处理帧间叠加（disposal 0/1/2/3），含局部更新和透明通道的 GIF 也能正常显示。
- 播放到结尾自动循环。

## 按键说明

| 按键 | 功能 |
| --- | --- |
| `空格` | 暂停 / 继续（即时取时） |
| `P` | 记录当前时刻为时间节点（最多 2 个，第 3 次按下无效） |
| `O` | 已有 2 个节点时，导出该时间段为 `_split.gif` |
| `Esc` | 清空所有时间节点 |
| 鼠标左键 | 点击底部进度条任意位置：跳转到该时刻并暂停（再按空格继续） |
| `Q` | 退出程序 |

典型流程：

1. `空格` 暂停 → `P` 记录时间 1；
2. `空格` 继续播放 → 到目标位置 `空格` 再次暂停 → `P` 记录时间 2；
3. 按 `O` 导出，得到 `xxx_split.gif`；
4. 选错了按 `Esc` 清空，重新打点。

除了用空格暂停找位置，也可以随时**用鼠标点击进度条直接跳到目标时刻**（跳转后自动暂停），再按 `P` 打点。

## 安装依赖

- Python 3.10+
- [pygame](https://www.pygame.org/)（画面与输入）
- [Pillow](https://python-pillow.org/)（GIF 解码与导出）

```bash
pip install pygame pillow
```

## 使用方式

```bash
# 直接指定 GIF 路径
python gif_splitter.py path/to/your.gif

# 不传参数则弹出文件选择对话框
python gif_splitter.py
```

程序启动后会先将 GIF 解码为纹理（大文件需几秒，窗口中有加载进度），随后自动开始播放。

## 导出区间规则

- 导出区间为半开区间 `[t1, t2)`：包含起始时刻所在帧，不包含结束时刻所在帧。
- 两个节点不分先后，自动以较小值为起点、较大值为终点。
- 区间内没有完整帧（例如两节点落在同一帧内）时会提示无法导出。
- 若区间起始位置落在 GIF 的局部帧上，第一帧使用当时的完整合成画面，并通过打包 RGB 查表**精确映射**回原始全局调色板（合成像素的颜色全部来自该调色板，零误差），后续帧沿用无损原始增量帧。
- 内容完全相同的连续帧会被合并为一帧（时长累加），播放效果与时长总量不变。

## 精度说明

- 暂停 / 打点时间基于系统时钟计算，而非逐帧累加，暂停响应快、时间读数准。
- GIF 帧时长本身通常为 10ms 的整数倍，因此**截取精度的上限是 GIF 的帧粒度**：落在同一帧内的两个时间点无法切出不同内容，这是 GIF 格式本身的限制。

## 内存占用

所有帧会预解码为纹理缓存在内存中以保证播放流畅、暂停即时。对于分辨率较高、帧数较多的 GIF（例如 1276×387、776 帧约占 760MB），请确保机器内存充足。
